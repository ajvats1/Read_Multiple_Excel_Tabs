# Excel Sheet Collator

A Python tool that reads multiple tabs from an Excel file and combines them into a single consolidated Excel output.

## Features
- Reads all worksheets from an Excel workbook
- Merges them into one output file
- Handles basic errors and reports failures
- Useful for reporting, finance, operations, and data cleaning tasks

## Use Case
This tool is helpful when data is split across multiple tabs and needs to be combined into a single dataset for analysis or reporting.

## Tech Stack
- Python
- pandas
- openpyxl
